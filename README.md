# Súper Kitchen

Menú móvil de Súper Kitchen. El repositorio conserva las rutas locales de fotos, tipografías y recursos originales. Vercel sirve la experiencia desde `preview-hero/` en la raíz del dominio.

## Vista previa local

Desde la carpeta del proyecto:

```powershell
python -m http.server 8765
```

Abre `http://127.0.0.1:8765/preview-hero/`.

## Publicación

Sitio estático servido por Vercel desde `vercel.json`; no requiere paquetes ni compilación.
